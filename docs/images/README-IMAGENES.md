# Instrucciones para agregar las imágenes

Para completar el README, necesitas guardar las 5 capturas de pantalla en este directorio con los siguientes nombres:

1. `screenshot-1-dos-relojes.png` - La gráfica de "LA CARRERA, SEGUNDO A SEGUNDO" con las curvas de presión y receptor libre
2. `screenshot-2-replay-receptor.png` - El replay de cancha con "Receptor gana la carrera" seleccionado
3. `screenshot-3-replay-sin-presion.png` - El replay de cancha con "Sin presión sobre el QB" seleccionado  
4. `screenshot-4-separacion-giro.png` - La gráfica de barras "SEPARACIÓN GANADA POR TIPO DE GIRO"
5. `screenshot-5-ventaja-lanzar.png` - Las dos gráficas de "% COMPLETO POR SEPARACIÓN AL LANZAR" y "% COMPLETO POR TENDENCIA AL LANZAR"

Una vez guardadas con estos nombres exactos, las imágenes aparecerán automáticamente en el README.
